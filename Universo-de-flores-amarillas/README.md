# Universo de flores amarillas

Experiencia web 3D de flores amarillas creada con JavaScript y Three.js.

## Ejecutar localmente

Necesitas Node.js y Python instalados.

```bash
npm install
npm run dev
```

Abre <http://127.0.0.1:8765/>.

## Comprobar la versión de producción

```bash
npm run build
npm run preview
```

La compilación genera `dist/`, que es la carpeta publicada por Vercel.

## Publicar

Consulta [PUBLICAR.md](PUBLICAR.md) para subir el proyecto a GitHub y desplegarlo en Vercel.
